## 双ISP不是营销词，它说的是两个字段

## 下单前必须知道的三条限制

这三条如果你没看到就付款，大概率会在收到机器后的一小时内想退款。

**第一，这个IP段禁ping。** 官方原话是“应IP提供方要求，此IP段禁了ping，不能ping是正常的，不影响使用”。这意味着你拿到IP后在本机ping、在第三方测速站ping，结果都是超时或100%丢包。这不代表线路差，也不代表机器坏了。判断机器是否正常，用SSH连、用网页访问，别用ping。网上那些“延迟测不出来”的评价，多半是没读这句话。

**第三，退款只退网站余额。** 官方在每个套餐下方都标了“特殊产品，仅退网站余额”。这不是原路退回支付宝，是退到你在丽萨主机的账户余额里，只能继续消费。下单前确认好配置，别想着“先买了不行再退”。

## 常见问题

**ping不通是不是机器坏了？**
不是。这个IP段被IP提供方要求禁ping，超时是设计如此。用SSH连接、用浏览器访问来验证机器状态。

**双ISP和原生IP有什么区别？**
原生IP说的是IP注册地和机房物理位置一致，解决的是“IP身份证对不对”。双ISP说的是ASN和Company两个字段都指向ISP运营商，解决的是“这个IP像不像家庭宽带”。前者是基础，后者是加强。做店铺、做账号矩阵，双ISP更稳；建站、跑代理、轻度使用，原生IP机房线就够。

**能用来建站吗？**
技术上可以，KVM架构、NVMe硬盘、支持装Windows。但这条线是非大陆优化线路且禁ping，面向国内用户的站点体验不会好。建站更该看丽萨的日本原生IP大带宽VPS那条线。

**能装Windows吗？**
官方页面明确写“支持安装Windows”。注意内存，1G的档位跑Windows会很吃力，至少从399元的2核2G起步。

**年付还是月付？**
看你打算用多久。少于三个月，月付。确定要跑一年且流量不大，999元年付比按月付基础版省一半以上现金。不确定就先月付，别为了省钱把自己锁在10G硬盘里。

**退款怎么算？**
服务开通48小时内可申请取消，但住宅IP属于特殊产品，只退网站余额，不退原支付渠道。另外官方条款里，带宽超额分配或流量大量使用的情况不在无条件退款范围内。
